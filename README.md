# 苍梵界理智系统

`cfj-sanity-system` 是苍梵界 DND5e 跑团使用的理智模块。它只处理理智规则：理智值生成、SAN 检定、SAN 豁免、理智损失、百分比理智状态、裂解/崩溃症状、短休和长休恢复。

本模块首选依赖 dnd5e / Tidy 角色卡的自定义属性 `SAN`。角色卡上需要有 `SAN` / 理智属性，玩家才能在卡面看到理智值、理智调整值，并点击 SAN 检定或 SAN 豁免。若角色还没有合法理智值，模块会提示初始化，不会把空值自动写成 0。

## 安装地址

在 Foundry 的模块安装器中填写：

```text
https://raw.githubusercontent.com/knightinrain/cfj-sanity-system/main/module.json
```

## 安装步骤

1. 打开 Foundry VTT 管理后台。
2. 进入 **Add-on Modules / 附加模块**。
3. 点击 **Install Module / 安装模块**。
4. 粘贴上面的 Manifest URL。
5. 安装模块。
6. 进入世界，在 **Manage Modules / 管理模块** 中启用 **苍梵界理智系统**。
7. 刷新一次世界页面。

## 建卡准备

推荐使用 Tidy 角色卡，并在属性区添加一个自定义属性：

| 项目 | 建议 |
| --- | --- |
| 属性缩写 | `SAN` |
| 中文名称 | 理智 |
| 用途 | 显示理智值、理智调整值，并提供 SAN 检定 / SAN 豁免入口 |

如果卡面还没有 `SAN` 属性，GM 可以先选中角色 token，在聊天区点击 **理智系统**，再点 **生成或连接理智值**。选择 **生成新理智值** 后，模块会投掷 `4d6kh3`，把结果写入：

- 最大理智；
- 当前理智；
- 角色卡 SAN 属性值；
- 选定资源栏的当前值和最大值；
- 理智状态与效应。

选择 **只连接/刷新** 时，模块不会重掷。它只读取现有理智数据并刷新状态。若最大理智无效、为 0 或未初始化，模块会提示处理，不会写入 0。

## 日常使用

### GM

1. 在聊天输入区附近点击 **理智系统**。如果按钮暂时没出现，在聊天框输入 `/理智`。
2. 聊天区会出现只对 GM 可见的 **苍梵界理智系统**控制台。
3. 点击 **发起理智判定**。
4. 设置类型、DC、同源、是否加入熟练、是否主动深入，并勾选目标角色。
5. 发送后，每个目标角色必须有在线的非 GM 拥有者。在线目标玩家会收到强制判定弹窗和自己的判定卡；没有在线玩家拥有者的角色会被跳过。

`/理智`、`/san`、`/sanity` 是 GM 备用入口。

### 玩家

1. 等 GM 发起理智判定。
2. 收到强制判定弹窗后，点击 **进行理智豁免** 或 **进行理智检定**。第一个弹窗必须完成掷骰才能关闭。
3. 玩家不需要设置 DC，也看不到 DC 设置项。
4. 掷骰完成后，玩家会收到一次性结果弹窗，可以手动关闭。
5. 也可以点角色卡上的 SAN 检定 / SAN 豁免。若 GM 已发起 pending 判定，卡面点击会使用 GM 保存的 DC、同源和风险参数。

## 推荐设置

- `默认 DC`：15
- `玩家必须等待 GM 发起`：开启
- `理智显示资源栏`：主资源栏；如果角色已有用途，改用副资源栏、第三资源栏或不写入资源栏
- `短休自动处理理智`：开启
- `长休自动处理理智`：开启
- `自动生成裂解/崩溃症状`：开启
- `显示 GM 明细`：开启

## 理智损失

理智豁免失败后才降低当前理智。

| 豁免结果 | 当前理智变化 |
| --- | --- |
| 成功 | 不降低 |
| 失败 | -1 |
| 失败 5 点或更多 | -2 |
| 失败 10 点或更多，或自然 1 | -3 |
| 主动直视、触碰、解读或深入同一来源 | 在上述基础上额外 -1；GM 必须提前提示风险 |

自然 20 成功。自然 1 按最强失败损失处理。

## 理智状态

理智状态只按当前理智比例判断。

```text
当前理智比例 = 当前理智 / 最大理智
```

最大理智无效、为 0 或未初始化时，模块不得计算理智状态，也不得把空值写回为 0。这样可以避免低最大理智角色一建卡就进入异常状态。只要当前理智等于最大理智，角色就是稳定。

| 当前理智比例 | 状态 | 生理反应 | 规则效果 |
| --- | --- | --- | --- |
| 85%-100% | 稳定 | 呼吸、判断正常 | 无影响 |
| 66%-84% | 动摇 | 耳鸣、冷汗、手抖、胃部收紧 | 下一次同源相关检定或豁免的结果减去 1d4 |
| 46%-65% | 失衡 | 视野发黑、短暂失语、心跳失序 | 对同源理智豁免具有劣势；不能从同源现象获得优势 |
| 21%-45% | 裂解 | 呕吐、鼻血、意识断片、错误确信 | 进入该状态时获得 1 个裂解症状 |
| 0%-20% | 崩溃 | 跪倒、抽搐、记忆错位、无法组织语言 | 进入该状态时获得 1 个崩溃症状 |

动摇和失衡只使用状态效果。只有裂解和崩溃会生成症状。角色卡效应、聊天结果和玩家结果弹窗都会显示当前理智、当前理智比例、已损失比例和理智状态。

## 症状

进入裂解或崩溃时，模块会自动抽取并添加对应症状。重复获得同名症状时不叠加。

## 休息规则

- 短休：移除裂解症状，然后重新计算理智状态。
- 长休：恢复 1 点当前理智，移除理智症状，然后重新计算理智状态。
- 当前理智不会超过最大理智。
- 休息后的重新计算不会因为角色仍在裂解或崩溃而立刻再生成一个新症状。

## 验证清单

启用模块后，用专用测试角色验证：

- 模块管理页面显示 **苍梵界理智系统**。
- GM 端聊天输入区附近出现 **理智系统** 按钮；若暂时不出现，聊天框输入 `/理智` 可以打开同一控制台。
- 玩家端不显示 GM 控制台按钮。
- GM 点击按钮后，控制台聊天卡只对 GM 可见。
- 场景工具栏里不再出现单独的理智按钮。
- GM 可以对选中角色生成新理智值，结果写入 SAN、当前理智和最大理智。
- 未初始化角色不会被自动写成 0。
- GM 发起一个非默认 DC 的理智判定。
- 目标玩家收到自己的判定卡，并能点击卡内按钮掷骰。
- 非目标玩家看不到该判定卡。
- 玩家掷骰时不能编辑 DC。
- 失败后当前理智降低，角色卡 SAN 数值变化。
- 进入裂解或崩溃时，角色获得可见状态和症状效应。
- 短休移除裂解症状。
- 长休恢复 1 点当前理智并移除理智症状。

## 版本记录

- `0.5.1`：补充 SAN 属性缺失提醒；写入理智值时同步填入 SAN 检定/豁免加值默认值 `0`，避免空值导致角色卡理智调整异常。
- `0.5.0`：模块收束为纯理智系统。停止加载骑乘、跟随、持续伤势和房规合集功能；说明文件改为只解释理智值、SAN 属性、理智生成、百分比状态、症状和休息处理。
- `0.4.1`：实测后修正 GM 入口挂载位置，优先放在右侧聊天骰子托盘下方；写入 SAN 时同步把空的 SAN 检定/豁免加值修成 `0`，避免 dnd5e/Midi 把空表达式判为非法。
- `0.4.0`：修复理智数据保护。未初始化、资源栏空值或读取失败不再被当作 `0` 写回角色卡；理智最大值/当前值先读 flags，角色卡 SAN 和资源栏只作显示同步。
